# 📱 Rate Repository App

Welcome to the **Rate Repository App**! This is a mobile application built as part of the [Full Stack Open](https://fullstackopen.com/en/) curriculum offered by the **University of Helsinki**. 

The app allows users to explore, search, filter, and review open-source GitHub repositories right from their mobile devices.

---

## ✨ Features

* 🔍 **Browse & Search:** Explore open-source repositories with dynamic search filtering and sorting options.
* 👤 **User Authentication:** Secure sign-up, login, and session persistence using JWT tokens.
* ✍️ **Repository Reviews:** Read existing community reviews and submit your own ratings.
* ⚡ **Seamless Navigation:** Smooth screen transitions, infinite scrolling pagination, and platform-adaptive UI styling.

---

## 🛠️ Tech Stack

* **Framework:** React Native & Expo
* **API & Data:** GraphQL & Apollo Client
* **Form Handling:** Formik & Yup
* **Routing & State:** React Router Native & AsyncStorage
* **Backend:** Express & GraphQL server (course setup)

---

## 🚀 Getting Started

Follow these steps to run the application locally on your machine or physical device.

### Prerequisites

* [Node.js](https://nodejs.org/) (v16 or higher recommended)
* **Expo Go** app installed on your phone ([iOS](https://apps.apple.com/app/expo-go/id982107779) / [Android](https://play.google.com/store/apps/details?id=host.exp.exponent)), or an active emulator running (Android Studio / Xcode).
